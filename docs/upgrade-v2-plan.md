# 升级 v2 方案（修订：延续原风格）

## 设计原则（用户确认）
- **延续原 Spring Initializr 布局与交互骨架**（Project / Language / Boot / 元数据 / Dependencies / Explore / Generate）
- **不做卡片大改版**；视觉以 **质感微调** 为主（阴影、圆角、边框、主色微提亮、字体层次）
- 中文化、架构上主页面、命名、Explore、模板与业务切片在原结构上「长出来」

## 需求对照

| # | 需求 | 方案 |
|---|------|------|
| 1 | 中文化 | 主流程/依赖/按钮/Explore i18n，默认 zh-CN |
| 2 | UI | 原布局 + 质感微调（非新皮肤） |
| 3 | Explore 即时 | 架构/模板/实体变更防抖重拉 zip；树即时刷新 |
| 4 | 命名 | 单应用 / **业务微服务** / **平台工程**（不对用户展示 six-module） |
| 5 | 业务切片 | 见下；含多实体、导入导出 |
| 6 | 模板 | 两架构各套模板（标准/增强） |
| 7 | 架构主页面 | 与 Project/Language 同级 Radio，移出 Dependencies |
| 8 | Explore 排序 | 文件夹优先，再文件名 |

## 业务切片

**接口勾选**：创建 / 详情 / 分页查询 / 更新 / 删除 / **导入** / **导出**

**多实体**：支持多个聚合；列表可 **收起/展开**；默认一个 `User`，可「添加实体」

**必填（每个实体）**：对象名、数据库、ORM（默认 MyBatis-Plus）  
**选填**：表名（可自动）、字段、接口勾选、中文描述

## 分期
- **P0**：中文 + 架构主页面 Radio + 命名 + Explore 即时/排序 + 质感微调
- **P1**：模板选择 + 多实体面板（收起）+ CRUD + 导入导出生成
- **P2**：平台增强模板等

## 视觉质感（在原 SCSS 上）
- 略加强卡片/面板边框对比与细阴影
- 主按钮/选中 Radio 质感（不改信息架构）
- 保持 Metropolis/现有字体体系，可微调字重；勿换成完全另一套 UI 语言
